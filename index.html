Prototype v1 — usage interne rédaction

Veille des députés normands

Répertoire consolidé des 28 députés des cinq départements normands, avec accès direct aux votes, textes, questions écrites et interventions vidéo.

Carte des 28 circonscriptions normandes, colorées par groupe politique du député élu. Cliquer sur une circonscription pour voir le nom du député, sa circonscription et son groupe.

À lire avant de publier ce chiffre : il ne s'agit pas d'un taux de présence physique brute — cette donnée n'existe pas de façon fiable et publique. C'est l'« indice d'activité » calculé par NosDéputés.fr (Regards Citoyens), qui agrège des marqueurs d'activité concrète : interventions en hémicycle et en commission, questions écrites, amendements signés, votes, rapports… Leur propre FAQ précise que le nom historique « semaines de présence » est trompeur. À utiliser comme indicateur d'activité parlementaire, pas comme preuve d'absentéisme.

Note méthodologique

Cet outil v1 est un répertoire curé, pas encore un flux automatisé. Il pointe vers les bonnes sources pour chaque type de suivi, en attendant le branchement de l'automatisation (étape 2).

Assiduité / indice d'activitéAPI ouverte NosDéputés.fr (Regards Citoyens) — /synthese/data/json, licence ODbLAutomatisé. N'est pas un taux de présence brute (voir avertissement dans l'onglet « Assiduité ») — indicateur composite d'activité parlementaire, affiché tel quel avec sa source.

Vue « Positions de vote » : les votes y sont regroupés par scrutin (et non plus un par député) — chaque carte montre le sujet, le résultat global, un graphique Pour/Contre/Abstention parmi les députés normands suivis, et la liste de leurs positions individuelles. Un bouton « ⬇ CSV » exporte les données de ce scrutin (député, département, groupe, position, conformité à son groupe).

À propos des couleurs de groupe : l'Assemblée nationale ne publie pas de couleur officielle par groupe politique. Les couleurs affichées suivent une convention éditoriale courante dans la presse française (proche de celle utilisée pour les graphiques d'hémicycle) — ce ne sont pas des couleurs officielles.

Limite du badge « contre son groupe » : il compare la position individuelle à la position majoritaire du groupe sur ce scrutin précis. Si le groupe est partagé de façon quasi égale (ex. 30 pour / 28 contre), le badge « dissident » peut apparaître alors que le vote reflète une vraie division interne plutôt qu'un désaccord isolé — le détail du décompte du groupe est inclus dans les données pour vérification.

Mise à jour des données : le script planifié réécrit directement ce fichier HTML chaque jour avec les données fraîches. Pas de serveur ni de manipulation nécessaire : il suffit d'ouvrir (ou de rafraîchir, si déjà ouvert) ce fichier pour voir les dernières données. Voir le guide d'installation fourni séparément.
