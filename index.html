Prototype v1 — usage interne rédaction

Veille des députés normands

Répertoire consolidé des 28 députés des cinq départements normands, avec accès direct aux votes, textes, questions écrites et amendements. Bâti à partir de l'open data de l'Assemblée nationale et de CIVIX.

Note de périmètre : l'API CIVIX couvre les votes, scrutins, dossiers législatifs et fiches députés. Questions écrites, rapports, propositions de loi et positions de vote viennent des fiches officielles de l'Assemblée nationale et sont désormais affichés ci-dessous. Les amendements déposés restent hors périmètre (pas de source par député exploitable simplement).

Note méthodologique

Cet outil v1 est un répertoire curé, pas encore un flux automatisé. Il pointe vers les bonnes sources pour chaque type de suivi, en attendant le branchement de l'automatisation (étape 2).

Positions de voteFiche AN — /dyn/deputes/{PA}/positions-de-voteAutomatisé (10 votes les plus récents, tous types confondus — y compris des votes très techniques sur des amendements en série). Pour/Contre/Abstention affiché.
Amendements déposésAucune page par député trouvée ; uniquement un moteur de recherche global ou l'archive complète en XML/JSONHors périmètre pour l'instant (sur demande).

Mise à jour des données : le script planifié réécrit directement ce fichier HTML chaque jour avec les données fraîches. Pas de serveur ni de manipulation nécessaire : il suffit d'ouvrir (ou de rafraîchir, si déjà ouvert) ce fichier pour voir les dernières données. Voir le guide d'installation fourni séparément.
